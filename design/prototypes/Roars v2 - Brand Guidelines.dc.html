Brand & build
guidelines
Everything established while building the Roars v2 pages — tokens, grid, components, page shell and content facts. Apply this to every new page so the set stays one design.
01 — Source of truth
Two sources, never mixed
Figma — “Astra agency”
Layout, type scale, spacing, colour neutrals, components. Values are copied verbatim from the file at its 1440 canvas — never rounded to a 4/8px grid.
roarsinc.com
All copy, names, numbers and imagery. People, project and client images are real Roars assets pulled from the live site.
The four original Roars - *.dc.html files are frozen. New work lands as Roars v2 - <Page>.dc.html.
02 — Colour
Astra’s neutrals, Roars’ one yellow
Astra’s system is black / white / grey with a single amber accent (rgb 255,170,1). That accent becomes Roars yellow #FFD400, used exactly as sparingly: hover fills, the wordmark badge, the scroll ring. Never a yellow background panel, never yellow body text.

03 — Typography
Inter, tight tracking, one exception
Inter 400–800 everywhere. Button labels are the single exception: Helvetica Neue Medium. Negative tracking is the signature — display type at −0.04/−0.05em, body and labels as tight as −0.06em.

06 — Page shell
The recipe every v2 page repeats
[data-fit]
outer wrapper, width 100%, overflow hidden. Its height is set to canvasHeight × scale.
[data-canvas]
the 1440-wide artboard, transform: scale(containerWidth / 1440), origin 0 0.
[data-topbar]
fixed bar, scaled by the same factor and left-aligned to the wrapper’s bounding box.
DARK ranges
array of [startY, endY] canvas bands that are dark. The bar recolours as it crosses them.
[data-ink] / [data-fill]
bar elements whose colour / background flip between #FFF and #141414 per band.
[data-ring]
scroll-progress ring: conic-gradient(#FFD400 <turn>, rgba(255,212,0,.14) 0turn), shown on light bands only.
wiring
fit() + tint() on mount, on resize, on scroll, and via a ResizeObserver on the wrapper.
helmet
Inter 300–800 from Google Fonts; body reset; a:hover { color:#FFD400 }; box-sizing border-box.
labels
each section carries data-screen-label (“Footer”, “Hero”…) for review context.
07 — Motion
Slow ease-out, nothing bouncy
Entrances use cubic-bezier(.16,1,.3,1) at ~1.1s with a short delay; hovers and bar recolours use .25s ease. The mark rotates 45° and turns yellow over light bands. Everything motion-related is skipped when prefers-reduced-motion: reduce matches.

09 — Imagery
Space for grounds, real photos for people
The space photograph (assets/space.jpg, often flipped with scaleY(-1)) is the dark-section art direction inherited from the Figma file — it is treatment, not content. Everything depicting Roars — founders, team, office, client work — uses real imagery from roarsinc.com. Small line marks (stars, asteroids, union) live in assets/ as SVG and are inverted with filter: invert(1) on dark grounds.
10 — New page checklist
Before calling a page done
✓File named Roars v2 - <Page>.dc.html; the four v1 files untouched.
✓1440 canvas, gutters at 39 / 1401, inner column at 503 where a rail is used.
✓Top bar copied intact, with DARK ranges updated to the new page’s dark bands.
✓fit() height constant matches the real canvas height.
✓Footer block with the 182px wordmark, nav and contact lines present.
✓Yellow appears only as hover, badge or ring — no yellow panels or yellow text.
✓Cross-links point to existing v2 files; every new page is linked from the footer nav.
✓Copy comes from roarsinc.com verbatim; no invented stats, names or client logos.
